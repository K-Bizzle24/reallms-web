A one-time setup. Many possibilities.

Make REALLMS part
of your workflow.

An API key lets your tools connect to REALLMS. First, get access through RTProjects, IU's resource-access portal.

  1. Find or create your RT Project.

    Sign in to RTProjects with your IU account.

    Does your PI already have a project? Check with them about being added and requesting a REALLMS allocation if one doesn't exist.

    Need a new project? Create one with a brief description of your research or coursework. Students will need their PI's username.

  2. Request a REALLMS API allocation, if needed.

    An allocation gives your project access to the service. Request one for your project, then wait for approval before creating a key.

    Already approved? Ask to be added to both the project and its allocation, then continue below.

  3. Generate your own API key.

    Open the approved allocation's page and create a key. Each collaborator needs their own; don't share keys or commit them to code.

  4. Connect a tool. Make a first request.

    Pick a recipe below. Start with cURL for a direct request, or connect a tool you already use.
