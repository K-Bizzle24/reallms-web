BROWSER ACCESS

An interface, already connected.

Anyone with an IU account can use Web Chat. No API key or separate access request is needed.

  1. Sign in with IU.

    Open Web Chat and choose Continue with IU Login.

  2. Choose a model.

    Send a message or upload a document to provide context.

  3. Continue the exchange.

    Ask follow-up questions and verify important outputs against your sources.

Open Web Chat ↗All Web Chat features

SHARED BY ALL API CONNECTIONS

First, your access.

  1. Find or create a project.

    Sign in to RTProjects. Check whether your PI already has a project and coordinate being added. If you need a new project, students need their PI's username.

  2. Request an allocation.

    Request a REALLMS allocation if the project lacks one. Wait for approval. Collaborators must be added to both the project and its allocation.

  3. Generate your own key.

    On the approved allocation's page, create an individual API key. Each collaborator needs their own. Never share keys or commit them to code.

Already have an approved allocation and your own key? Continue to the configuration below. Full API access guide.

DIRECT API / cURL 8.3+

Make a direct request.

A minimal Chat Completions request, without an AI client. Other capabilities use their own endpoints and request formats.

See the API guide and cURL example.

TERMINAL CLIENTS

Connect from your terminal.

Configure OpenCode or Pi to use a REALLMS language model. Text responses and agent tool calls are separate capabilities; tool calling is not verified here.

Configuration references: OpenCode V2 and Pi. Use the REALLMS base URL and your own key from the API guide.

CODE EDITOR / CONTINUE

Connect inside VS Code.

Use Continue in Chat mode with a REALLMS language model. This configuration does not enable autocomplete or establish agent tool support.

See Continue's provider reference and the REALLMS API guide.

External clients do not automatically inherit REALLMS data approval. Check their data handling before connecting. Examples are documentation-backed, not authenticated integration tests. Never enter a key on this page.
